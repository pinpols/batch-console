# 快速入门

> **关注角色**：全部角色
> **操作级别**：只读与个人偏好
> **典型入口**：登录页、顶栏租户、全局搜索、语言、主题、账号菜单

## 登录

1. 打开管理员提供的控制台地址。
2. 输入用户名和密码。用户名可能由租户管理员创建，也可能由平台管理员统一分配。
3. 如果出现验证码，完成验证后重新提交登录。
4. 登录后先确认右上角用户名和顶栏当前租户。

登录失败时不要连续盲目重试。优先区分密码错误、账号停用、验证码、网络错误和服务不可用。错误提示中的 Trace ID 可用于后端定位，但不要提交密码或加密后的登录请求内容。

## 密码提示

首次登录、管理员重置密码或密码临近过期时，控制台可能显示修改密码提示。提示本身不等于当前所有页面都被强制阻断；是否必须立即修改由后端会话策略决定。

修改密码时：

1. 从账号菜单进入个人信息或密码修改页面。
2. 输入当前密码、新密码并再次确认。
3. 使用系统给出的强度规则，不复用近期密码。
4. 提交成功后按提示重新登录。

## 当前租户

顶栏租户决定大多数列表、统计、作业定义和运行记录的数据范围。

- `ROLE_ADMIN` 与 `ROLE_AUDITOR` 通常可以搜索并切换租户。
- `ROLE_TENANT_ADMIN` 与 `ROLE_TENANT_USER` 通常固定在登录账号所属租户。
- 切换租户后等待页面重新加载，再执行查询或写操作。
- 复制链接给他人时说明租户；同一路由在不同租户下可能显示完全不同的数据。

## 全局搜索与导航

- 侧边栏按工作台、运行监控、告警与投递、作业与流程、文件、调度治理、系统管理分组。
- 顶栏搜索用于快速找到当前角色可访问的页面。
- 搜索结果只代表当前会话可见入口，不会绕过权限。
- 隐藏的详情页或设计器通常从列表页的行操作进入，不一定长期占用侧边栏位置。

## 语言、主题和密度

- 语言切换影响页面文案，不改变数据内容、业务编码和后端返回的自由文本。
- 主题可在浅色、深色或跟随系统之间切换；登录页默认遵循已保存偏好或系统设置。
- 表格密度、列显示和已保存筛选属于个人浏览器偏好；清理浏览器数据后可能恢复默认。
- 中英文切换后仍保持原语言的内容，通常是业务数据、枚举缺少翻译或后端原始错误信息，应记录页面和字段反馈。

## 页面上的常见结构

| 区域       | 作用                                   | 使用建议                       |
| ---------- | -------------------------------------- | ------------------------------ |
| 状态段     | 快速切换全部、运行中、成功、失败等集合 | 先选状态，再设日期和关键字     |
| 筛选区     | 日期、对象编码、Trace ID 等组合查询    | 条件过多时先重置再逐项添加     |
| 实时监控条 | 展示自动刷新状态和最后更新时间         | 执行操作后确认刷新时间变化     |
| 行详情抽屉 | 查看完整字段、日志、步骤和关联记录     | 从摘要进入，不必横向堆满表格列 |
| 空状态     | 区分暂无数据、筛选无结果和加载失败     | 按辅助文案决定新建、重置或重试 |

## 退出登录

公共或共享终端使用完必须从账号菜单退出。关闭浏览器标签不一定立即撤销服务端会话。账号权限发生变更后，也建议退出再登录以刷新权限与菜单。

## 权限自查

所有角色都可以从右上角账号菜单进入“权限自查”。页面分别展示四类正式角色、后端 authority 清单、前端界面能力档和当前实际可见页面。界面能力档仅用于前端组件分级，不代表第五种业务角色或新的后端授权。
