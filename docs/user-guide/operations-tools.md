# 运维工具

> **关注角色**：平台管理员、平台审计员、租户管理员、租户用户
> **入口**：桌面端顶栏“工具菜单” → “运维工具”

运维工具用于在处理批次、文件和调度问题时做快速检查。所有工具集中在一个右侧抽屉中，不增加侧边栏页面，也不改变后端调度、文件路由或重试策略。

## 权限范围

| 能力 | 平台管理员 | 平台审计员 | 租户管理员 | 租户用户 | 权限说明 |
| --- | --- | --- | --- | --- | --- |
| 时区换算 | 可用 | 可用 | 可用 | 可用 | 纯本地换算 |
| Cron 预览 | 可用 | 可用 | 可用 | 可用 | 只读调用后端 Quartz 预览 |
| 本地文件检查 | 可用 | 可用 | 可用 | 可用 | 纯本地读取，不上传 |
| 导出命名预览 | 可用 | 可用 | 可用 | 可用 | 只读后端预览，按当前租户计算 |
| 重试时间线 | 可用 | 可用 | 可用 | 可用 | 纯本地估算，不修改策略 |
| 命令面板对象定位 | 可用 | 可用 | 可用 | 可用 | 结果受后端租户与数据权限限制 |
| 批次日窗口查询 | 可用 | 可用 | 可用 | 可用 | 只读查询 |
| 批次日 Catch-up | 可用 | 不可用 | 不可用 | 不可用 | 高风险写操作，仅 `ROLE_ADMIN` |

前端根据当前会话隐藏无权执行的 Catch-up 操作，后端仍是最终授权边界。工具抽屉中的五项能力均为只读或浏览器本地计算，不授予新的配置写权限。

## 时区换算

选择来源时间和来源时区，再选择最多四个目标时区。结果同时显示标准时刻、当地时间和 UTC 偏移。对于年内偏移发生变化的时区，页面会标记“有变化”，便于识别夏令时风险。

适合全部角色核对告警、运行记录和跨区域交接时间。输入表示指定时区下的墙上时间；遇到夏令时跳变或重复时段时，应再以业务记录中的 ISO 时间点为准。

## Cron 预览

Cron 工具复用作业配置页的 Quartz Cron 组件。可使用常见预设、查看人类可读描述，并通过后端 Cron 预览接口取得下次执行时间。

本地描述只帮助阅读。表达式是否合法、采用哪个时区以及实际触发时间，均以后端 Quartz 返回和作业配置为准。

## 本地文件样本检查

选择文件后，浏览器只读取前 128 KiB，检查编码、BOM、换行符、常见分隔符和疑似二进制特征。文件内容不会上传。对于不超过 64 MiB 的文件，可按需计算完整 SHA-256。

该检查适合在上传前发现常见格式问题，但不替代后端模板校验、字段映射、业务规则或病毒扫描。最终是否可接收，以文件渠道和后端处理结果为准。

## 导出命名规则预览

填写命名规则、文件格式、业务日和可选占位符值后，点击“后端预览”。页面调用与导出 Worker 共用的后端解析器，返回最终文件名。

该能力只负责导出文件名预览，不按文件名选择导入模板，也不参与文件路由。导入流程仍使用模板编码、渠道和后端业务规则。

## 重试时间线

选择固定或指数退避策略，设置基础延迟、重试次数、倍数、延迟上限和抖动比例。表格展示每次重试的标称延迟，以及可能发生的最早和最晚时间。

时间线用于配置评审和故障沟通。真实重试从每次失败完成时开始，并可能受任务运行时长、调度器负载、并发控制和后端环境配置影响。

## 对象快速定位

顶栏命令面板支持菜单、最近页面和后端实体搜索。还可直接输入：

| 输入格式 | 结果 |
| --- | --- |
| `30296` 或 `job:30296` | 打开作业实例详情 |
| `file:42` | 打开文件列表并定位 File ID |
| `trace:request-id` | 打开 Trace 诊断 |
| 作业编码、工作流编码或文件名片段 | 搜索后端实体并打开对应页面 |

对象是否可见仍受当前租户和后端权限控制。搜索不到对象时，先核对顶栏租户，再到对应列表页扩大日期范围。

## 批次日计算入口

批次日与业务日历不是独立工具页。进入“调度治理 → 批次日与窗口”后，在窗口详情顶部切换业务日和日历编码，页面会加载对应窗口状态和作业汇总。Catch-up 仍在该业务页面内发起并审计。
