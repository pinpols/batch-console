## 测试数据污染

测试在本地 dev Postgres 里累积了：

- **ta / tb 租户**：完整 8-sheet seed（pipeline / workflow / job / file_channel / alert_routing / pipeline_step / workflow_node / workflow_edge）
- **api_key / notification_channel / notification_rule / webhook_endpoint / system_parameter / user_account**：数条 CRUD 流程产物（多数 CRUD 测试走完闭环会自删）
- **audit_log / config_change_log / event_outbox / event_outbox_retry / approval_command**：追加型日志表，持续增长
- **Trigger**：被反复注册/注销/暂停/恢复
- **alert_event**：ACK / closed 若干

**不会造成问题**（dev 库无生产数据，seedTenant 再跑会 upsert 覆盖）。想清可以 truncate 日志类表或整个 `docker compose down -v` 重置。
