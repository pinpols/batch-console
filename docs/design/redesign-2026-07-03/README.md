## 1. 设计方向(一句话)

**深色优先(dark-first)的数据/状态驱动运维台**:严重度分色的指标、领域汇总卡、看板式队列、等宽 ID/时间戳、丰富但克制的顶栏。不是营销页,是长期在线的运维控制台。

四个最显著的升级点:

1. **Dark-first**:整体深色底(近黑蓝),卡片深灰 + 细边框;浅色为可选主题(顶栏有切换)。
2. **严重度分色**:所有关键数字/状态按语义上色(见 §3.2),问题项(失败/离线/迟到)用**红色 + 左边框强调**跳出,0 值/正常用**中性灰**,不再"满屏等权"。
3. **领域汇总卡**:列表页顶部一排可点的汇总卡(如文件列表的 今日到达/待处理/已归档/迟到),点击=带过滤跳转。
4. **看板 + 等宽**:Outbox/事件这类队列用**看板列**;所有 code/ID/traceId/事件名/时间戳一律**等宽字体**。

## 3. 设计系统(token 级,前端可直接落）

> 以下为从原型归纳的规范值;实现时统一进 `src/styles/tokens.css`(已有 dark 段),**新增/覆盖变量,不散落字面量**。

### 3.1 主题与中性色(dark)
| 用途 | 值(近似) |
|---|---|
| 画布底 `--color-bg-canvas` | `#0b0f14` |
| 页面底 `--color-bg-page` | `#0f1419` |
| 卡片底 `--color-bg-card` | `#161b22`~`#1a1f26` |
| 卡片边框 `--color-border` | `#2d333b`(细 1px) |
| 主文字 | `#e5eaf0` / 次 `#b8c0cc` / 三级 `#8b95a3` |
| 主色/链接 | 蓝 `#3b82f6`(hover `#2563eb`) |

### 3.2 严重度色（关键:所有数字/状态徽标按此上色）
| 语义 | 色 | 用在 |
|---|---|---|
| 正常/成功 | 绿 `#22c55e` | 在线 Worker、已归档、已处理 |
| 进行中 | 蓝 `#3b82f6` | 运行中任务、处理中 |
| 需关注 | 琥珀 `#f59e0b` | 待审批、待处理、SLA 违规、Draining、延迟、重试中 |
| 严重/失败 | 红 `#ef4444` | 失败任务、离线 Worker、投递失败、迟到(**卡片加红色左边框**) |
| 空/中性 | 灰 `#6b7280` | 0 值、已归档(中性场景) |

### 3.3 字体
- 正文:`PingFang SC / -apple-system / system-ui`,正文 14、次要 13、卡片大数字 28–32、标题 20/16。
- **等宽**(`--font-family-mono`):**所有** code / ID / traceId / 事件名(`report.generated`)/ 渠道(`channel:recon`)/ 时间戳(`07-03 06:02:11`)/ 文件名。数字列 `tabular-nums`。

### 3.4 卡片 / 圆角 / 状态徽标
- 卡片圆角 10–12px、1px 边框、几乎无阴影(扁平,靠边框分层)。
- **状态 = 彩色圆点 + 文字**(`● 已处理`),**不是**大色块 tag;圆点用 §3.2 语义色。
- 汇总卡:标题(次色)+ 大数字(语义色)+ 右上角 `›` 可点。

### 3.5 顶栏 / 侧栏
- 顶栏:← → 导航 · 面包屑 · 租户选择 · **⌘K 搜索** · 通知(徽标)· 中/EN · 移动 · 帮助 · **主题切换** · 用户菜单。
- 侧栏:分组图标栏,BC 蓝 logo;≤1440 收起为纯图标 + hover flyout 文字。

## 4. 页面模式(复用模板)

- **列表页模板**(文件列表/作业定义/Worker/租户实例…):`页头(标题+副标题+右操作[主操作/刷新/列设置])` → `领域汇总卡(4)` → `筛选面板(字段等宽对齐 + 搜索/重置)` → `表格(选择列 + 等宽 ID/时间 + 圆点状态 + 行操作:主动作 + ⋯ 溢出)` → `分页`。
- **看板页**(Outbox 投递 / 事件告警):按状态分列(待/中/重试/失败),每列事件卡(等宽 ID + 事件名 + 目标渠道 + 时间 + 单动作),列头带计数 + 顶部批量动作(全部重试)。
- **Dashboard**:tab(卡片指标/趋势/分布/扩展面板)+ 严重度分色 KPI 卡网格 + 维护横幅。
- **详情**:状态头(关键状态大字 + 严重度色)+ 分栏/描述列表(避免 20 个 tab),ID/traceId **一键复制**。

## 5. 与现状差异 & 落地建议(功能零破坏)

新稿**不改数据流/接口/路由**,只换视觉与交互层。建议分期,每期一页样板跑通再铺开:

| 期 | 内容 | 说明 |
|---|---|---|
| P0 · 设计底座 | tokens.css 落 §3 全部变量(dark 为默认或可切)、mono/tabular 全局、状态圆点组件、汇总卡组件 | 一次到位,后续页面复用 |
| P1 · 列表页模板 | 用 §4 模板重做 1 页(建议**文件列表**)做样板,验证筛选栏等宽 + 表格新风格 + 汇总卡 | 已有 `ListPageQueryBar` 等宽修复(PR #179)是基础 |
| P2 · 铺开列表页 | 作业定义 / Worker / 租户实例 / 发布管理 … 套模板 | 按 §2 清单 |
| P3 · 看板页 | Outbox 投递 / 事件告警 | 新看板组件 |
| P4 · Dashboard + 详情 | 严重度分色 KPI(替换等权卡片)、详情状态头 + 复制 traceId | 收口 |

**红线**:沿用既有约束——`v-safe-html`、`useTenantReload`、类型走 `api.generated.ts`、i18n 全量、颜色/间距走 token(禁裸 hex/px)。详见 `../../CLAUDE.md`。
