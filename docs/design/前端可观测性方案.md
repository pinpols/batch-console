# 前端可观测性方案

## 整体架构

前端可观测性分三层，各司其职：

```
┌────────────────────────────────────────────────────────────────┐
│  前端（Vue）                                                     │
│                                                                  │
│  ┌─────────────┐  ┌──────────────────┐  ┌───────────────────┐  │
│  │ 本地操作日志  │  │ 行为埋点 SDK      │  │ Sentry 错误监控   │  │
│  │ logger.ts    │  │ telemetry.ts     │  │ sentry.ts         │  │
│  │ localStorage │  │ → 后端 REST      │  │ → Sentry Server   │  │
│  └──────────────┘  └────────┬─────────┘  └────────┬──────────┘  │
└─────────────────────────────┼──────────────────────┼─────────────┘
                              ↓                      ↓
                 /api/console/telemetry/events    Sentry / GlitchTip
                              ↓
                  ┌───────────┴───────────┐
                  │ 方案 A（轻量）         │ 方案 B（专业）
                  │ Kafka → Loki          │ Kafka → ClickHouse
                  │ Grafana 看板           │ Grafana / Superset
                  └───────────────────────┘
```

| 层级 | 定位 | 存储 | 实现 |
|------|------|------|------|
| 本地操作日志 | 离线排障兜底 | 浏览器 localStorage | `src/utils/logger.ts` |
| 行为埋点 SDK | 页面访问、点击、API 调用分析 | 后端 Loki / ClickHouse | `src/utils/telemetry.ts` |
| Sentry 错误监控 | JS 异常、白屏、性能追踪 | Sentry Server | `src/utils/sentry.ts` |

---

## 一、本地操作日志（logger）

离线可用的环形缓冲区日志，不依赖后端，用于用户侧排障。

### 核心文件

`src/utils/logger.ts`

### 存储

- **运行时**：模块级变量 `buffer: LogEntry[]`，环形缓冲区，上限 500 条
- **持久化**：`localStorage`，key 为 `batch-console-oplog`

```json
{
  "seq": 42,
  "entries": [
    {
      "id": 1,
      "ts": "2026-04-10T08:00:00.000Z",
      "category": "route",
      "level": "info",
      "message": "页面切换：首页",
      "detail": { "path": "/ops/summary", "from": "/login" }
    }
  ]
}
```

- 每 10 秒落盘一次 + 页面关闭前落盘
- localStorage 写满时自动缩容到 200 条；数据损坏时静默重置

### 日志分类

| 类别 | 级别 | 采集位置 | 说明 |
|------|------|----------|------|
| `route` | info | `src/router/index.ts` afterEach | 路由切换 |
| `click` | info | `v-track-click` 指令 | 按钮/操作点击 |
| `api` | info / error | `src/api/interceptors.ts` | API 请求结果 |
| `error` | error | `src/main.ts` 全局错误处理 | Vue 异常、window.error、unhandledrejection |

### 查询与导出

```ts
import { queryLogs, exportLogsAsJson, clearLogs } from '@/utils/logger'

queryLogs({ category: 'api', level: 'error', keyword: '/api/job', since: '2026-04-10' })
const json = exportLogsAsJson()  // 导出 JSON 供排障下载
clearLogs()                       // 清空本地日志
```

### 数据结构

```ts
type LogCategory = 'route' | 'click' | 'api' | 'error'
type LogLevel = 'info' | 'warn' | 'error'

interface LogEntry {
  id: number
  ts: string
  category: LogCategory
  level: LogLevel
  message: string
  detail?: Record<string, unknown>
}
```

## 二、行为埋点 SDK（telemetry）

批量上报用户行为到后端，用于功能使用率分析、访问统计。

### 核心文件

`src/utils/telemetry.ts`

### 设计

- **内存队列**：事件先入队列，每 15 秒批量 POST 上报
- **队列上限**：100 条，超过立即 flush
- **单批上限**：50 条
- **页面关闭**：`visibilitychange` + `beforeunload` 用 `sendBeacon` 兜底
- **失败处理**：静默丢弃，不影响业务

### 上报端点

`POST /api/console/telemetry/events`

### Payload 格式

```json
{
  "app": "batch-console",
  "userId": "zhangsan",
  "tenantId": "tenant-001",
  "ua": "Mozilla/5.0 ...",
  "screen": "1920x1080",
  "sessionId": "1712736000000-a1b2c3",
  "events": [
    {
      "type": "page_view",
      "name": "首页",
      "ts": "2026-04-10T08:00:00.000Z",
      "page": "/ops/summary",
      "props": { "from": "/login" }
    },
    {
      "type": "click",
      "name": "触发 Job",
      "ts": "2026-04-10T08:00:05.000Z",
      "page": "/job/list",
      "props": { "jobId": 123 }
    }
  ]
}
```

### 事件类型

| type | 采集点 | 说明 |
|------|--------|------|
| `page_view` | router afterEach | 页面访问 |
| `click` | v-track-click 指令 | 按钮/操作点击 |
| `api_call` | interceptors 成功响应 | API 调用（含耗时） |
| `api_error` | interceptors 错误响应 | API 错误 |
| `js_error` | main.ts 全局捕获 | JS 运行时异常 |
| `custom` | 手动调用 track() | 自定义事件 |

### 手动调用

```ts
import { track, trackPageView, trackClick, trackApi, trackApiError, trackJsError } from '@/utils/telemetry'

trackPageView('首页', { path: '/ops/summary' })
trackClick('触发 Job', { jobId: 123 })
trackApi('GET /api/jobs', { status: 200, durationMs: 120 })
track('custom', '导出报表', { format: 'xlsx', rows: 5000 })
```

### 环境变量

| 变量 | 说明 | 默认值 |
|------|------|--------|
| `VITE_TELEMETRY_ENDPOINT` | 上报端点 | `/api/console/telemetry/events` |
| `VITE_TELEMETRY_ENABLED` | 是否启用 | `true` |

## 三、Sentry 错误监控

专业错误监控，自动采集 JS 异常、性能数据，支持 Source Map 还原。

### 核心文件

`src/utils/sentry.ts`

### 特点

- **按需加载**：DSN 为空时不加载 SDK，零 bundle 开销（动态 import）
- **浏览器追踪**：集成 `browserTracingIntegration`，自动关联路由
- **噪音过滤**：忽略 ResizeObserver、chunk 加载失败等无意义异常
- **租户标签**：自动附加 `tenantId` tag，便于按租户筛选
- **采样率**：生产 0.2，开发 1.0

### 环境变量

| 变量 | 说明 | 默认值 |
|------|------|--------|
| `VITE_SENTRY_DSN` | Sentry DSN 地址 | 空（不启用） |

### 部署步骤

1. 安装依赖：`npm install @sentry/vue`
2. 在 `.env.production` 中填入 `VITE_SENTRY_DSN=https://xxx@sentry.example.com/1`
3. CI 中上传 Source Map：`sentry-cli sourcemaps upload dist/`

## 四、采集点一览

所有埋点采用**双写**策略：本地日志（localStorage 兜底排障）+ telemetry 上报（后端分析）。

| 采集点 | 文件 | 本地日志 | Telemetry | Sentry |
|--------|------|----------|-----------|--------|
| 路由切换 | `src/router/index.ts` | logRoute | trackPageView | 自动（browserTracing） |
| 按钮点击 | `src/directives/trackClick.ts` | logClick | trackClick | - |
| API 成功 | `src/api/interceptors.ts` | logApi(info) | trackApi | - |
| API 失败 | `src/api/interceptors.ts` | logApi(error) | trackApiError | - |
| Vue 异常 | `src/main.ts` errorHandler | logError | trackJsError | 自动捕获 |
| window.error | `src/main.ts` | logError | trackJsError | 自动捕获 |
| unhandledrejection | `src/main.ts` | logError | trackJsError | 自动捕获 |

## 五、点击埋点用法

使用 `v-track-click` 指令（同时写入本地日志 + telemetry 上报）：

```vue
<!-- 字符串形式 -->
<el-button v-track-click="'触发 Job'">触发</el-button>

<!-- 对象形式（携带附加数据） -->
<el-button v-track-click="{ action: '审批通过', id: row.id }">通过</el-button>
```

## 六、初始化

在 `src/main.ts` 中一次性完成三层初始化：

```ts
initLogger()                              // 本地操作日志
initTelemetry({ endpoint, enabled })      // 行为埋点上报
initSentry({ app, router, dsn })          // Sentry 错误监控
```

## 七、后端对接

后端已适配前端 Payload 格式（见 OpenAPI `receiveTelemetryEvents`），字段完全一致。

```
POST /api/console/telemetry/events
Content-Type: application/json
Body: TelemetryPayload（见上方 Payload 格式）
```

处理流程：console-api 接收 → 写 Kafka topic `frontend-telemetry` → Loki/ClickHouse 消费 → Grafana 看板展示。

### 推荐 Grafana 看板维度

- 按 `page` 统计页面 PV / UV
- 按 `type=click` + `name` 统计功能使用率
- 按 `type=api_error` + `props.status` 统计接口错误率
- 按 `userId` / `tenantId` 过滤特定用户行为
