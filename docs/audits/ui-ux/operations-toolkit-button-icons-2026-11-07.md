# 全站操作按钮图标（2026-11-07）

状态：已按本决定改完。分母是 `src` 下全部 `.vue`（页面、抽屉、移动页和共享组件）。规则沿用[操作按钮的颜色与图标](../../engineering/ui-interaction-conventions.md#操作按钮的颜色与图标)，不另造图标，也不给每个按钮都加。

## 决定

表示一次操作的按钮用已有的 14–16px Lucide 线性图标加文字。刷新、重试加载、复制、取消、关闭、重置、分页、列设置、向导上一步/下一步、Cron 预设和纯跳转保持文字。表格行内操作继续走 `RowActions`，那里已经按动作配了图标。桌面和手机上同一动作用同一图标：通过用 `CircleCheck`，拒绝用 `CircleX`。

## 已补

| 图标 | 用在 |
| --- | --- |
| `Plus` | 作业「新建向导」「快速新建」；作业详情里新建日历、新建窗口 |
| `Upload` | 作业「导入配置包」；文件列表的上传、选择文件、提交上传 |
| `Play` | 作业手动触发、工作流触发、批量触发、打开设计器旁的批量触发、试运行提交 |
| `Pencil` | 工作流列表「设计器」 |
| `Save` | 编辑抽屉 `FormDrawer` 的提交；维护设置的保存 |
| `Send` | AI 发送；自助服务四张申请表的提交；修改密码提交 |
| `RotateCcw` | 作业运行批量重试 |
| `CircleCheck` / `CircleX` | 审批批量通过、批量拒绝，与手机端一致 |
| `ScanSearch` | 运维工具「规则预览」 |

新建类列表页头（租户、用户、作业定义以外的工作流新建、模板、参数、API Key、配额、队列、告警路由）原来就已经是 `Plus`。行内查看、重试、删除仍由 `RowActions` 提供。

## 保持无图标

- 刷新、重新加载、关闭、取消、重置、清空筛选、分页、列设置、向导步骤、Cron 预设、假日月份切换。完整值浮层里的复制是右上角图标，长内容在浮层内换行。
- 计算校验值、登录主按钮、PWA 更新、验证码重试。它们是工具或整页提交，不是工具栏操作。
- 「去维护日历 / 队列 / 配额」「查看全部」「打开诊断」这类跳到别的页面的按钮。
- 终止、下线等还没有现成图标的危险动作，不新造一个图标顶上。
