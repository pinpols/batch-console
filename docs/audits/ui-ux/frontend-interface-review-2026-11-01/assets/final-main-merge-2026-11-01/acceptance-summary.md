## 中断与重验

启动时 Kafka 初始化超过过短检查窗口，shell 未 fail-fast，误启动一次专属 Orchestrator；停止后数据库事务回滚、Flyway 无失败记录，重新完成初始化后迁移至 V375。四项业务场景当时尚未运行。

首次导出运行发现专属 Worker 监听通配地址后立即终止；使用正式 API 限定该夹具运行及分区取消，清理计数全为零。第二次运行的导出文件已生成，但验收环境遗漏对象 namespace，读取和清理选错路径；核对物理对象与记录的大小和 SHA 一致后，仅删除那个精确对象并确认不存在。补齐 namespace 和 loopback 设置后第三次运行通过，真实 Worker 实际监听 loopback。

最初等待图夹具使用空 payload，真实恢复器拒绝无效等待，导致首次图成功、后续图出现已取消；下一版夹具缺少父 Workflow 身份，被数据库准入约束拒绝。两次失败及清理证据保留；最终修正后的独立父子请求在真实恢复器运行后仍处于等待，完整测试通过。

验收结束后，仅停止本例 PID，并移除经标签确认的专属容器、卷和网络；再次查询均不存在。私有临时环境文件已删除。截图仅含生成的测试用户及租户，不含真实业务数据；此精简包不包含 Cookie、口令或原始服务日志。
