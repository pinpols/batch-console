方法遵循 `frontend-ui-ia-review`。分母是 `src/views`、`src/views-mobile`、`src/components` 里每一处 `ProTable`、`el-table` 和移动列表空分支，对照 `DataState`、`EmptyState`、`ListEmptyState` 与 `ProTable` 的空槽实现。卡片列表（告警、配额、发布、Worker 卡片）一并列入。图表空态、单元格「—」不记为列表偏差。

## 结论

主列表空态目前有四套表现：列头被整块空态换掉、表内只剩一行纯文字、筛选后出现重置、以及通用「暂无数据」和本页说明混用。前两套和「有筛选却没有重置」偏离[列表空态](../../engineering/ui-interaction-conventions.md#列表空态)。通用文案本身可以保留给日志和明细。

根因在共享组件，不在某一页的文案：

- `DataState` 在 `!hasData` 时渲染空态，不再渲染默认插槽里的表格，列头消失。
- `ProTable` 只在没有筛选时使用 `#empty`。一旦 `has-active-filters` 为真，退回 `empty-text` 纯文字，页面放进空槽的重置和新建引导都不会出现。
- 未提供 `#empty` 的 `el-table` / `ProTable` 使用 Element Plus 默认空文案，只有一行字。
- `src/styles/element-override.css` 把全部 `.el-empty__image` 降到透明度 0.42。这是为默认插画写的，自定义空态图标被一起淡化。

用户已要求按约定整改。代码已按本记录和[列表空态](../../engineering/ui-interaction-conventions.md#列表空态)改完，是否通过以台账里的验证范围为准。

## 偏差

### 列头消失

`DataState` 包住表格，没有行时整表被换成 `EmptyState`。登录账户在这种状态下仍有图标和重置，但列头不在。

登录账户、标签资源、执行日志页签、渠道回执、死信、重试、配置变更日志、配置密钥、配置同步日志。

### 表内纯文字

表头还在，空态是 `empty-text` 或默认「暂无数据」，没有图标。

触发器、终端投递、审计、操作审计、执行日志页、作业步骤、文件模板、文件渠道、到达组、系统参数、批次日列表、AI 调用记录、流水线观测四张表、事件目录两张表、Worker 渠道表、队列、批次窗口、业务日历、日历假日、调度快照三张表、调度队列、三类依赖等待、资产新鲜度、作业监控策略、批次窗口页内两张表、容量画像中的表、发布治理侧栏表。

依赖等待和「无计划发生」已经是专用短句，整改时保留句子，只补图标并把空态放进表体。

### 有筛选时退回纯文字，或仍引导新建

`ProTable` 在 `has-active-filters` 时丢掉 `#empty`。下面这些页无筛选时已是图标空态，加了筛选就变成一行字，重置也不见了：租户、工作流定义、API Key、通知规则、通知渠道、Webhook、投递日志、审批、补跑审批。

告警路由、配额策略、发布记录时间线有查询栏，但空态不看筛选，筛选后仍可能显示新建。

### 文案

通用「暂无数据」用于日志、回执、审计和明细，与约定一致，不要求改成各页长说明。可新建的主列表（作业定义、文件、租户、API Key、通知规则等）继续用本页说明。筛选无结果统一用「筛选无结果」，不用「当前租户还没有……」。

## 不纳入

详情从属表、向导、预览和抽屉结果表保持短文案：工作流运行节点表、作业实例详情、作业定义详情中的关联表、文件审计抽屉、工作流定义里的预览表、配置包导入与填写说明、租户复制 / 批量开户对话框、认领任务抽屉、批次日重放的预览和条目表、OIDC 绑定抽屉、原子任务类型的参数表、干跑结果、重试时间线、关联文件页签。分区视图挂在单次作业实例下，同样保持短文案。

图表空态（报表趋势、运维概览、容量图）按图表约定保留坐标框架，不套列表空态。

## 移动端

`src/views-mobile` 的列表空态都是 `.m-empty` 短文字，彼此一致，不换成桌面大空态。审批已区分搜索无结果，作业运行已区分仅看超时。Worker、Outbox、告警在 `filtered.length === 0` 时仍用同一句「没有数据」。文件列表空态用桌面的 `empty.default`。

## 附带

自定义空态图标放在 `.el-empty__image` 里，被全局透明度 0.42 和饱和度滤镜一起淡化。整改列表空态时，这条约只作用于 Element Plus 默认插画。
