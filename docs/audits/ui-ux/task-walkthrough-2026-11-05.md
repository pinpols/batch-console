# 任务走查审计（2026-11-04 ~ 11-05）

按真实任务走完整流程，找“难用”与“看不懂”的地方。方法遵循 `frontend-ui-ia-review`：先固定任务与角色分母，再在本地真实后端逐步截图、记录控制台错误与失败请求，最后按类型分级。本记录是本轮发现与处置状态，不是全站验收结论。

## 做得好的地方

- 手动触发后给出“请求已受理”对话框并提供“查看实例”，直接落到带筛选的运行列表。
- 配置包导出后可原样走导入预览，预览按工作表汇总有效、错误行数，并明确“预览通过，可应用”。
- 只读用户的写按钮统一禁用，悬停提示“当前角色没有该操作权限”。
- 重跑确认框写清“基于相同 jobCode + bizDate 派发新实例，原实例数据保留，下游可能重复处理”。
