# CI/CD E2E 验证(2026-05-28)

试验:从开 PR 到容器跑新代码,**无人工干预**。

## 流程

1. `verify/e2e-cd-2026-05-28` 分支加本文件
2. `git push` + 开 PR(本文件 = PR 内容)
3. `gh pr merge --admin --squash --delete-branch`(因 author=owner)
4. 部署机 `BatchDeployFE` 计划任务(每 1 min 跑)检测到 origin/main HEAD 推进
5. 脚本 `deploy-fe.ps1` 自动 `git pull` + `docker compose -p batch-platform-console up -d --build --wait`
6. `batch-console` 容器重建 + healthy
