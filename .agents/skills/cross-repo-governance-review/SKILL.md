# 前后端治理总控入口

20域矩阵、模式、状态口径和交付格式统一维护在[配对后端总控](../../../../file-batch-system/.agents/skills/cross-repo-governance-review/SKILL.md)。执行双仓任务先读取该完整技能，按双方实际工作树、分支、HEAD和用户范围核对基线；不以同名分支、历史报告或后端通过替代前端当前证据。配对路径不在默认位置时先定位真实仓库。

前端职责按现有入口承接：

- `frontend-quality-review`：代码Bug/变更及综合质量结论。
- `frontend-engineering-governance`：前端架构、规约、门禁和供应链。
- `frontend-ui-ia-review`：UI、交互、美观与视觉一致性的具体检查。
- 其余API、状态、i18n、测试、部署和文档按风险进入专项。

本入口只统筹双仓覆盖、跨仓责任和证据闭环，不复制第二套20域矩阵，不重复已经完成的同基线专项。单点或仅前端任务直接使用上述技能。评估、实施、验证及Git/环境/发送等操作依用户授权分别执行；未知、未运行、SKIP与PASS保持权威总控的区别。
