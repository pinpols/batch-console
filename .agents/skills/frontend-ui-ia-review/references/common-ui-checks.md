# UI、交互与视觉常见问题检查

## 如何使用

本页是现有UI技能的按需检查表，不新增设计系统、产品需求或自动门禁。当前规则见[设计Token](../../../../docs/engineering/design-tokens.md)、[交互约定](../../../../docs/engineering/ui-interaction-conventions.md)和[测试指南](../../../../docs/testing/README.md)。

对每个适用项记录页面/组件、目标任务、角色/租户、状态、视口/主题/语言、检查步骤及证据；区分功能Bug、可用性、规范偏差和建议。实际未操作的组合写明未验证，不能按截图数量、路由数量或关键词命中统计“已修问题”。

## 常见问题与复核方式

| ID / 审查面 | 常见问题 | 复核方法与边界 |
|---|---|---|
| UI-01 信息层级与导航 | 标题和当前对象不清，筛选/维护工具抢主操作注意力，租户选择像自由文本，菜单选中与实际页面不同。 | 从角色任务走列表→详情→返回/刷新/深链；核对全局租户、对象名、面包屑和主次动作。数据密集界面保留必要密度，不为装饰增加无信息卡片或留白。 |
| UI-02 对齐、间距与规格 | 同类按钮/输入/标签高低不一，边距无节奏，文字基线错位，颜色/圆角/阴影局部漂移。 | 对照运行时token、Element Plus映射和共享组件，检查computed style、CSS覆盖顺序及弹层teleport。源码定义相同不等于运行样式一致；特殊图表/布局保留有依据差异。 |
| UI-03 表格与行操作 | 表头/列宽失衡、长列挤走操作、sticky遮挡/弹层裁切，排序/分页/选择反馈不一致，纯图标不可理解。 | 检查空/单行/多页、长ID、横向滚动、固定列、“更多”菜单和row key；打开详情与动作必须命中当前选中身份。复用RowActions，不只看首屏无溢出。 |
| UI-04 筛选与查询 | 即时控件意外提交其他字段草稿，半个日期范围触发请求，搜索不回第一页，重置重复请求或轮询清空筛选。 | 区分编辑草稿与已生效条件；按交互约定检查输入、Enter、搜索、重置、URL与请求参数，连续快速操作及回退后回读结果。 |
| UI-05 表单与向导 | 默认值/依赖字段不清，placeholder代替label，错误离字段太远，失败后丢输入，步骤切换悄悄保存或丢草稿。 | 测空值/边界/非法值、依赖切换、服务端拒绝、返回再编辑；检查字段说明、校验时机、footer主次和原生submit/Enter。规则以真实契约为准，不只验证前端required。 |
| UI-06 弹窗、抽屉与确认 | 复用弹窗显示上个对象，旧响应覆盖新目标，连点多开，关闭后焦点丢失，未保存改动被ESC/遮罩丢弃。 | 连续开关/切换对象并制造慢响应，核对标题、表单、请求ID与结果归属；按既定关闭/脏数据策略验证ESC、遮罩、返回和焦点进入/恢复，避免无依据全禁关闭。 |
| UI-07 动作、权限与重复提交 | 当前状态不支持的动作仍可点击，权限不符却只失败toast，提交可重复，危险确认缺少对象/范围，批量部分失败显示全成功。 | 按角色×状态验证显隐/禁用原因、loading与单次提交；确认文案核对租户、对象和影响范围，逐项结果对账。前端显隐不替代后端授权。 |
| UI-08 加载/空/错/陈旧状态 | 请求失败伪装“暂无数据”，未知显示0/成功，刷新把旧数据当实时，部分依赖失败导致整页误导。 | 分别模拟或观察慢、空、网络/业务失败、重连和部分结果；核对错误、重试、最后成功时间及陈旧提示。未抓到数据与明确零值不可混用。 |
| UI-09 反馈与提示 | 成功/失败级别错误，toast挡操作或移动导航，长Trace挤坏按钮，错误没有修正入口，背景状态反复弹窗。 | 检查短/长消息、连续反馈、复制/详情/重试、关闭后可恢复性；关键失败不能仅依赖短暂toast，复制目标应完整且安全。 |
| UI-10 长文本、数值与日志 | 长编码/路径/多行JSON溢出，关键信息被截断，HTML实体裸露，单位/精度/时间不清，复制的是省略值。 | 用长/空/未知/多字节样本和大数核对换行、ellipsis、tooltip、详情与复制值；安全纯文本/结构化摘要保留原始详情，不用不安全HTML修排版。 |
| UI-11 图表、DAG与比较视图 | DAG节点黑块无字、连线/标签重叠、图例/单位缺失、未知分母伪造百分比、缺一个版本快照却生成差异统计。 | 实际查看文字/颜色/缩放/弹层与安全SVG；对账数据、状态口径和完整快照。空/单点/大范围/部分缺失分别判定；截图、连线存在或组件渲染不证明数据可信。 |
| UI-12 主题、密度和语言 | 暗色placeholder/次级文字不可读，主题切换弹层未跟随，紧凑密度挤压控件，英文长译文破坏布局。 | 对改动覆盖浅/深色、实际支持的密度及中英文，检查表格/表单/弹层和动态内容；以当前token和任务可读性判断，不设主观“美观分”或任意像素还原百分比。 |
| UI-13 窄屏、移动与缩放 | 工具栏/弹层横溢，底部操作被键盘/导航/安全区挡住，横竖屏错位，禁止放大或窄屏点击目标重叠。 | 分开实际桌面窄屏与/m移动路由，检查滚动容器、footer、软键盘及缩放；模拟器与真机证据分开，桌面缩窄不等于移动流程验收。 |
| UI-14 键盘与语义可访问性 | Tab顺序不符任务，焦点不可见/困住/丢失，图标无可访问名称，错误未关联字段，状态只用颜色。 | 实际键盘完成查询/编辑/弹层并检查DOM role/name、错误关联和状态反馈；hover tooltip不自动证明有可访问名称。axe、截图和手工键盘证据各有边界。 |
| UI-15 跨页与异步上下文 | 切租户/Tab/路由后旧响应改当前页，深链缺上下文无恢复入口，保存后列表/详情矛盾，返回丢查询。 | 沿选中对象→请求目标→返回投影→业务/持久结果核对；快切与乱序回复交 `frontend-state-data-flow` 深查，契约/权限交 `frontend-api-contract`，不在UI层伪造完成状态。 |
| UI-16 上传、下载与复制 | 上传取消/重试反馈不清，下载失败被当成功，文件限制/部分结果不显示，一次性秘密被持久化。 | 检查选文件/限制/进度/取消/重试及失败恢复，核对实际目标与结果；导入业务和模板由既有专项承接，不用直接SQL造出UI成功。对象URL和敏感内容按生命周期清理。 |
| UI-17 共享组件与浏览器 | 公共组件修一页坏多页，公共token覆盖未生效，控制台warning/pageerror被忽略，浏览器行为差异漏验。 | 追代表性调用方式、嵌套/弹层状态与受支持浏览器，记录实际console/network/DOM；warning先查用户影响和根因，不继承历史严重度或无依据调整安全/兼容策略。 |
| UI-18 视觉与交互证据 | 新基线直接覆盖真实退化，截图状态不同却比较像素，只有按钮存在/点击就宣称业务完成。 | 前后对比固定构建、角色、数据、视口、主题与语言；记录操作步骤和结果。视觉基线变更要解释设计意图，不能为绿色直接接受差异；未执行项/条件跳过保持原状态。 |

- [2026-06-25可用性审查](../../../../docs/audits/ui-ux/frontend-usability-2026-06-25/README.md)：保留空态误导、工具栏层级、日志摘要、全局租户上下文与移动视觉一致性的方法。
- 旧页面数、分数、P级、测试数和“已修复”只属于原基线。当前缺陷必须重读当前源码、构建与页面，不复活旧固定布局、组件或部署参数。
