# Batch Console 重设计 — 设计规格

> 配套文件:`batch-console-设计定稿.html`(离线单文件,双击即可打开)
> 源文件:`Batch Console 重设计.dc.html`

## 1. 设计语言

- **风格**:Linear / Vercel 式冷静极简 + Ant Design 企业风密度
- **主题**:深色为默认,浅色可切(顶栏 ◐);全部颜色走 CSS 变量,双主题自动适配
- **字体**:界面 IBM Plex Sans;代码/编号/数值 IBM Plex Mono
- **控件基线**:统一高度 32px(紧凑模式 28px);圆角 8px;卡片 12px
- **强调色**:蓝(accent);语义色 成功=绿 / 告警=黄 / 危险=红
- **图标**:统一 20–24px 线性 SVG(1.5–2px 线宽),无字形/emoji
- **密度**:可切舒适 / 紧凑(表格行高联动)

## 2. 全局框架

- **侧边栏**(IA v3,7 组):工作台 / 运行监控 / 告警与投递 / 作业与流程 / 文件 / 调度治理 / 系统管理。手风琴折叠,**默认仅当前所在组展开、其余收起**;可整体收缩为图标栏(记忆状态);每项单色线性图标 + 激活左强调条
- **低频项不进侧边栏**:配额策略 / 队列配置 / 运行窗口 / 业务日历(admin 季度级操作)仅通过 ⌘K 可达
- **顶栏**:面包屑 · 租户切换 · 全局搜索(⌘K)· 通知 badge · 中/EN · 文档入口 · 主题切换 · 移动端预览 · 用户菜单
- **命令面板**:⌘K 打开,跨页面跳转(含侧边栏全部 + 低频 4 项)
- **全局导航**:返回 / 前进
- **反馈**:Toast(操作确认)+ 二次确认弹窗(危险/不可逆操作)
- **RBAC**:按角色控制菜单与操作可见性,顶部可切换角色预览

## 3. 信息架构(IA v3 —— 当前实现)

> **v2 已废弃**。v2 把“看告警”与“配置通知”同置运行监控(概念层不同)、作业与文件同组(用户角色不同)、高低频混放。v3 拆分:告警与投递独立(告警→路由→投递→订阅闭环)、文件域独立、低频项进 ⌘K。

### 工作台
- **控制面板**:4 tab —— 卡片指标(11 指标卡,点击跳对应页)/ 趋势(7 日成功·失败堆叠)/ 分布(按作业类型,可点)/ 扩展面板(待处理卡 + 最近失败实例 + 运行状态);顶部 打印/PDF
- **审批中心**:通用审批 + 补跑审批 双 tab;通过/驳回带二次确认;行点开详情抽屉
- **自助服务**:6 类运维操作卡(手动触发 / 失败重跑 / 补跑 / 暂停恢复 / 导出 / 配置变更)
- **报表中心**:趋势分析(KPI + 7 日趋势图 hover 明细)+ 导出中心(3 类报表生成卡 + 历史文件下载列表)双 tab

### 运行监控(纯观测)
- 全部运行 / 作业运行 / 作业步骤 / 工作流运行 / Trace 检索 / 运行诊断

### 告警与投递(闭环)
- **告警中心**:未处理 / 已确认 / 全部 分组;确认、静默 24h;告警路由规则抽屉
- Outbox 投递 / 通知管理

### 作业与流程(job owner)
- 作业定义(向导新建 / Bundle 导入 / 新增;行内 手动触发·编辑·⋯菜单;详情/编辑抽屉三态)
- 流水线定义 / 工作流定义 / Workflow 设计器 / 配置批量导入(3 步向导)

### 文件(独立域)
- 文件列表 / 文件到达组 / 文件流水线可观测 / 文件模板 / 文件渠道

### 调度治理(高频)
- Worker 管理(在线/Draining/离线概览可筛选 + 负载条 + Drain/恢复;执行通道 tab)
- 触发器 / 调度快照 / 批次日 / 批次日重放

### 系统管理
- 租户实例 / 登录账户 / 发布管理 / 变更与同步 / 权限自查 / API Key / 系统参数 / 标签管理 / 审计日志 / 操作审计 / 事件目录 / AI 助手 / 个人中心

### 仅 ⌘K 可达(低频 admin)
- 配额策略 / 队列配置 / 运行窗口 / 业务日历

### 全局
- **Workflow 设计器**:双模式 —— 设计器(节点库拖拽 + 画布 + 属性面板 + 小地图)/ 只读(静态 DAG)
- **移动端预览**:值班场景 4-tab(概览 / 运行 / 告警 / 我的),iPhone 外壳

## 4. 通用列表页能力(所有 CRUD 页复用)

- 列表 + 筛选搜索栏(关键字 + 下拉,32px 对齐)
- 新建 / 编辑 / 详情:统一右侧抽屉,三态(查看 / 编辑 / 新建)
  - 编辑态按字段语义分控件:文本输入 / 固定下拉 / 可搜索下拉 / 多选反选 chip
  - 详情含:基本信息栅格 + 执行步骤时间线(运行类)+ 活动记录时间线
- 多选批量:行/表头复选框 → 批量条(重试 / 导出 / 取消)
- 列设置:显隐任意列
- 统一分页(总数 · 每页 · 页码)
- 状态徽章(语义色 + 圆点);统计卡可点击筛选(› 提示 + Toast 反馈)

## 5. Mockup 取舍(实现端补真实逻辑)

1. 统计卡/分布条点击 = 筛选反馈(Toast),真实过滤逻辑接后端
2. 下拉、日期选择器为展示态,数据源接实现端
3. 分页页码为静态示意
4. AI 助手回复为示例文案

## 6. 术语对齐(设计 ↔ 实现)

流水线定义 · 报表中心 · 作业运行 · 全部运行 · 文件列表 · 租户实例 · 登录账户 · 发布管理 · 变更与同步 · 权限自查 —— 统一到实现端命名。
