# Batch Console 重设计资料

本目录是 2026-07 前端重设计的最新权威入口。旧的长期架构文档仍在 `docs/design/`,但不再作为本轮视觉重设计依据。

| 文件                                       | 用途                                                     |
| ------------------------------------------ | -------------------------------------------------------- |
| `frontend-redesign-implementation-plan.md` | 工程实施计划:IA 口径、Phase 拆分、目标文件、验收门禁     |
| `export/batch-console-设计规格.md`         | 设计规格:设计语言、全局框架、IA v3、通用列表页能力       |
| `Batch Console 设计定稿.html`              | 可离线打开的高保真定稿                                   |
| `Batch Console 重设计.dc.html`             | 设计源文件归档,用于后续重新导出                          |
| `refs/tokens-handoff.css`                  | 设计 token 交付,Phase 1 时映射进 `src/styles/tokens.css` |
| `refs/`                                    | 精选参考图和 token 色板                                  |
| `screenshots/`                             | 设计工具导出的完整页面/组件截图                          |
| `uploads/`                                 | 设计源文件引用的上传素材归档                             |

实施时以 `frontend-redesign-implementation-plan.md` 为入口,不要直接照搬 HTML 内的静态 mock 数据。
