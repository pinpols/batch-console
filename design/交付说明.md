# Batch Console 设计交付包

## 文件清单
| 文件 | 用途 |
|---|---|
| `Batch Console 重设计-离线版.html` | **主交付物**。全站页面 + 组件总览 + 响应式/动效规格,单文件自包含(JS/CSS/骨架全内联,仅字体走 CDN)。用 devtools 抠精确值。 |
| `全局质感合集.html` | Toast / 空态 / 加载骨架 单张质感 tile。 |
| `tokens-handoff.css` | 色板 / token 的 CSS 变量,前端直接映射。 |
| `tokens-color-sheet.html` | 色板可视化表。 |
| `batch-console-设计规格.md` | 规格文档。 |

## 深链(在离线版 .html 后加锚点)
- 作业运行列表母版 → `#instances`
- 抽屉三态 → `#jobs/view` · `#jobs/edit` · `#jobs/create`
- 组件总览(弹窗/Toast/空态/骨架/分页) → `#states`
- 响应式与动效规格 → `#spec`
- 告警 `#alerts` · 审批 `#approvals` · 文件 `#files` · Worker `#workers` · 报表 `#reports` · 自助 `#selfservice` · Outbox `#outbox`

## 前端还原三条纪律
1. 用 devtools 抠离线版源文件,**别对着截图目测**(hover/focus 态只在源码里)。
2. 颜色**映射到 CSS 变量**(`--bg-card` `--accent` `--text-2`…),别硬编码 hex;变量定义在源文件顶部 `[data-bc-root]`,深/浅两套齐全。
3. 控件基线走变量:`--control-h:32px`(紧凑 28)、`--row-py:10px`;字体 IBM Plex Sans + IBM Plex Mono。
